One engine, three faces

💧

Context Hydration

Sources flow in — Claude plans, sessions, changelogs, git history. Hydra classifies, tags, and links them automatically. Watch mode keeps it real-time.

🧠

Oracle Graph

GPU-accelerated force-directed graph shows how everything connects. Find gaps, trace provenance, discover relationships you didn't know existed.

🎨

Beautiful UI

Purple-on-obsidian design system with smooth animations. Light and dark mode. Built for humans who care about their tools.

⌨️

CLI + MCP

Full command-line interface for scripting and CI. MCP server for agent integration. Same engine, any surface.

🔧

Obsidian Plugin

One unified plugin replacing Smart Connections + Dataview + Colored Tags. Calls the Swift binary for heavy lifting.

📱

Cross-Platform

macOS, iOS, and CLI — all sharing the same Swift core. Tailscale-aware path resolver connects vaults across machines.
